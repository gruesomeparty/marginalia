A document-review tool an agent hands to a human.

An agent writes a spec, a schema, a diagram or a diff, and needs a person to actually read it.

Marginalia renders that document as a page worth reading, collects comments anchored to individual blocks, and writes them back as append-only JSONL the agent consumes directly. No database, no accounts, no copy-and-paste step.

The loop

The agent serves a document and gets a URL. You annotate. The agent reads the events, revises, and records which note each change answered — and you confirm or reopen. Nothing in the log is ever rewritten.

What makes it different

Every one of these exists because a review that misleads you is worse than no review at all.

Comments survive edits — or admit they didn't

Each block carries an ID, a quote and a content hash. Edit the document and notes re-anchor themselves; a note written against text that has since changed comes back flagged stale rather than silently pointing at the wrong paragraph.

Comment on a sentence

Select text and the note is about that. It survives unrelated edits elsewhere in the paragraph, and goes stale only when its own sentence changes.

Click the arrow in the diagram

Mermaid flowcharts render as real pictures whose shapes carry the same anchors as the source. Click the retry edge, comment on the retry edge. Source is one toggle away.

Review a diff

Unified diffs anchor by file and hunk — the thing a human is most often asked to approve. Markdown, .proto, JSON, YAML and TOML too.

The agent answers back

A question gets a reply threaded under it. The agent records which note a change addressed — and the claim is checked against the document, so claiming a fix without touching the text says so.

Built for agents to call

Ships an MCP server: serve a review, read only what's new by cursor, block until the human is done. No scraping terminal output.

What it deliberately doesn't do

Scope choices, not a roadmap.

  • No authentication. Anyone who can reach the URL can write to the log. That's fine for 127.0.0.1 and for a Tailnet; it is not fine on an untrusted network, and it won't pretend otherwise by growing a token flag.
  • One reviewer at a time. Two people on one document write to one log with no identity and no conflict story.
  • It never edits your document. Suggested edits are reported, with whether they still apply cleanly. You apply them.
  • No database, no accounts, no hosted service. A log file next to your document. For someone off your machine there's a one-file export that loads nothing at all.
